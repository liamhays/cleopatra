# Caesar Seeker data scraper

If you watch the Network tab in your browser's developer tools when
you type a zip code in at
[https://order.littlecaesars.com/en-us/order/pickup/](https://order.littlecaesars.com/en-us/order/pickup/),
you can see that the webpage is simply sending a barebones POST
request to whatever server Little Caesar's uses to find the locations
nearest to your zip code.

The USPS maintains a big Excel spreadsheet of every zip code at
https://postalpro.usps.com/ZIP_Locale_Detail.
